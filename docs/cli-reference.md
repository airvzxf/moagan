# preflight

_Smoke-test the END-TO-END pipeline (discover + run --mode fast) against the real provider. Two-run flow:_

Smoke-test the END-TO-END pipeline (discover + run --mode fast) against the real provider. Two-run flow:

1. `moagan discover` with cardinalidad 8 (1 sketch per dimension × facets_per_dimension = 1), 1 temperature (1.0), 1 replica. Produces a `run_id` with a persisted `sketches/` library. 2. `moagan run --mode fast` that consumes the discover run's library via `--context <run_id> --context-full` (the `Full` scope loads every text-like file under the run dir, including `sketches/*.json`).

Cost: ~60-120 s of API budget, ~3 MB of disk. Exercises both the discovery code path (matrix build + coordinator) AND the run --mode fast path (intake → clarify → sketch → judges → tag → cluster → facets → portfolio), so a preflight that succeeds is a strong end-to-end signal. Both run ids are printed on stdout so the operator can drill into either one.

The pre-PR-564 version only wrapped `discover`, which missed the upstream intake/clarify phases. PR #565 wrapped `run --mode fast` only, which duplicates the existing fast-mode test coverage.
