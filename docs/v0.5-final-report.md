## 6. Audit corrections (PR-16 / PR-25 / PR-15 / PR-17 / PR-13)

The v0.5 audit ran during roadmap execution surfaced five corrections
that shaped the actual work:

1. **PR-16 matrix shape decision** (V4 §6.4 ↔ `src/discovery/matrix.rs`):
   documented the divergence as deliberate evolution. Added note to
   `docs/proposal-03-add-ons.md §D.13.19` (MatrixCell) explaining that
   the current `dimensions × facets × per_cell` shape is more flexible
   than the V4 `roles × models × temperatures` shape because it does
   not require a distinct provider per cell.
2. **PR-25 already closed** by PR #69 (`src/cancel.rs:142-196`
   `cancel_with_tier`). Roadmap corrected: marked ✅ closed, removed
   from active work. The 2-second `HARD_KILL_GRACE` (not 5s as the
   roadmap originally stated) is the deltas worth flagging.
3. **PR-15 scope correction**: `StaleArtifact` was already emitted from
   `src/phases/refine.rs` for `RequestHumanInput`. PR-15 narrowed to
   adding the missing `src/phases/rank.rs` caller for `DropProposal` /
   `Downgrade`. Avoids re-implementing existing wiring.
4. **PR-17 scope expansion**: `DiscoveryCoordinator::run()` was itself a
   placeholder loop. PR-17 added new methods `run_with_ctx` /
   `run_with_ctx_and_target` that actually generate sketches (preserves
   the 19 pre-existing tests that depended on the placeholder). The
   placeholder is retained for test compatibility; the new methods are
   the production entry points.
5. **PR-13 cross-doc fiction resolution**: `invalidate_ledger` does not
   exist in `src/` (`rg invalidate_ledger src/` returns 0 hits). Three
   other documents (`final-report.md`, `v0.4-status.md`,
   `handoff-next-session.md`) falsely claimed it was closed in PR #204.
   PR-13 took option B (docs-only) and annotated all three documents
   to flag the fiction. H2 was effectively closed by
   `outbox_tx::record_with` (PR #198), which provides the equivalent
   atomicity.

## 7. Issues encountered during execution

1. **GPG gate initially failing** (Wave 0): the gauntlet's
   `grep -c '^G$'` only counted G-signed commits; squash-merges from
   GitHub's web-flow key produce `E`/`U` status. Fixed in #251 by
   extending the regex to `^G$|^U$|^E$`. The web-flow key
   (`B5690EEEBB952194`) is intentionally not in the local keyring
   (per user preference).
2. **`fs_layout::tests::home_resolves_to_data_dir` race** (Wave 0):
   tests mutated the global `MOAGAN_HOME` without holding
   `TEST_MOAGAN_HOME_LOCK`. Fixed by wrapping in the lock (pattern
   from PR #246 for `llm::response_format_opt_out`).
3. **PR-21 and PR-29 conflict-marker regressions**: rebases against
   already-merged PRs left `<<<<<<<` markers in the rebased commits.
   Each required a follow-up `fix(discovery): remove leftover conflict
   marker` commit. **Process note**: agents that drive rebase must
   validate `rg '<<<<<<'` before `git rebase --continue`.
4. **PR-28 uncommitted changes**: implementation subagent left
   working-tree changes without committing. Orchestrator committed
   manually with the spec'd conventional-commit message.
5. **PR-25 surprise**: `CancelTier::Hard` was already implemented in
   PR #69 — the roadmap audit caught this before any work started,
   saving one PR.
