## 5. LLM provider changes

### 5.1 — K.4 rate-limiting avanzado (#484)

`feat(research): Retry-After parsing, jittered backoff, per-host
circuit breaker`. Tier A #15 ships as a single PR.

- **`Retry-After` parsing** (HTTP 429 / 503): the fetcher reads
  the `Retry-After` header (delta-seconds or HTTP-date) and
  schedules the retry accordingly.
- **Jittered exponential backoff**:
  `backoff = min(2^attempts * base_ms, max_backoff_ms) ±
  rand_jitter(0.2)`.
- **Circuit-breaker per-host**: 5 failures in 60 s ⇒ open circuit
  for 30 s. New `HostCircuitBreaker` in
  `src/research/circuit_breaker.rs` integrates with
  `HostRateLimiter`.
- ~14 new tests in `src/research/fetcher.rs` and
  `src/research/circuit_breaker.rs` simulating upstream 429 +
  `Retry-After` header + burst failure pattern.

### 5.2 — Discovery contradiction judge (#486)

`feat(discovery): replace contradiction stub with LLM-as-judge
detector`. The 86-LoC stub (`src/discovery/contradiction.rs`)
is replaced by the new `Role::ContradictionJudge` role. The
prompt template lives at
`src/prompts/contradiction_judge_v1.md` and returns the JSON
schema `{pair: [id1, id2], severity: enum, evidence: string,
suggestion: string}`. The wire-up
(`src/phases/discover_contradict.rs:17`) now invokes the new
LLM-call dispatch instead of the heuristic stub.

### 5.3 — Adversary refinements (#488)

`feat(adversary): add 5 D.12.5 add-on patterns
(shared_blind_spots, unanimous_claims_without_evidence,
hidden_assumptions, omitted_risks, unverified_claims)`. The
twelve-pattern `AdversaryPattern` enum (7 canonical from
PR #277 + 5 new) is wired through `AdversaryPhase` with
fixtures and per-pattern test cases.

### 5.4 — Telemetría push-side (#494)

`feat(telemetry): push-side SaturationEvent + alerts sub-command`.

- **`SaturationEvent` runtime**: new event type emitted when
  the `RateLimitConfig` near-saturation threshold is crossed.
- **Alert channels**: `moagan telemetry alerts list` reads the
  cross-run CSV aggregation.
- **In-process push**: integrates with `tokio::sync::watch` so
  long-running `moagan run` invocations surface saturation
  events without polling.
- ~12 new tests in
  `src/telemetry/{alerts,saturation,events}.rs`.

## 6. Hardening

### 6.1 — Cross-run retention sweep (#492)

`feat(telemetry): cross-run retention sweep for orphan SQLite
rows`. New `moagan telemetry cleanup --cross-run` sub-command
runs `DELETE FROM calls WHERE run_id NOT IN (SELECT run_id FROM
runs)` with `--dry-run` by default. The per-run retention
policy (already shipped) handles fresh runs; the cross-run
sweep closes the orphan-row gap that arises when a run is
deleted from the `runs` table without a cleanup hook.
~8 new tests in `src/telemetry/retention.rs::tests_cross_run`
and `tests/integration_phase_i.rs`.

### 6.2 — K.4 multi-host auth (#498)

`feat(research): per-host bearer token resolution (K.4 sub-3)`.
`HostPolicy` is extended with bearer tokens per host via the
`[research.auth]` config block. The fetcher resolves the
bearer token from the per-host config block or falls back to
the `GITHUB_TOKEN` / `MODELS_DEV_TOKEN` environment variables
already wired in PR #212. ~6 new tests in
`src/research/auth.rs` and `src/research/host_policy.rs`.

## 7. Embedders

### 7.1 — `RemoteEmbedder` adapter (#496)

`feat(embedder): add RemoteEmbedder HTTP adapter
(OpenAI/Cohere/Voyage/Custom)`. The second embedder ships,
alongside `HashingEmbedder`.

- **Trait**: `RemoteEmbedder` (in `src/llm/embedder_remote.rs`).
- **Adapter wire formats**: 4 providers covered.
  - **OpenAI-compatible**: `POST {endpoint}/v1/embeddings`
    with `{input, model}` body; response `{data[0].embedding}`.
  - **Cohere-compatible**: `POST {endpoint}/v1/embed` with
    `{texts, model}` body; response `{embeddings[0]}`.
  - **Voyage-compatible**: `POST {endpoint}/v1/embeddings`
    with `{input, model}` body; response `{data[0].embedding}`.
  - **Custom**: configurable JSON request / response paths via
    `request_template` + `response_path` config.
- **Config block**: `[[embedder_remote]]` in
  `moagan.toml`, with `provider`, `endpoint`, `api_key_env`,
  `model`, `dimensions` (and `request_template` /
  `response_path` for `provider = "custom"`).
- **No Anthropic SDK** — same constraint as the rest of the
  LLM stack: `reqwest` + `rustls` only.
- ~10 new tests in `src/llm/embedder_remote.rs` and
  `tests/integration_embedder_remote.rs`.

## 8. Documentation

### 8.1 — ADR-0001 differentiated no-go list policy (#479)

`docs/adr/0001-no-go-list-policy.md` formalises the policy:

- **`petgraph 0.6`**: admitted (optional, behind `feature =
  "dag"`). Rationale: the linear `phases/` vector is fine for
  v0.8; the DAG backend unblocks v0.9 features that depend on
  cycle detection.
- **`comfy-table 7.1`**: deferred to v0.9. Rationale: tables
  are cosmetic; `insta` snapshots cover regressions.
- **`proptest 1.4`**: admitted in `[dev-dependencies]` only.
  Rationale: property-based tests for cache hashes /
  serialisation / IDs without touching the release binary.

The ADR ships with an executable guard
(`scripts/check-no-forbidden-crates.sh`) that enforces the
three policies. AGENTS.md is updated with the differentiated
allow-list entries.

### 8.2 — PR #421 closure rationale (#480)

`docs/pr421-closure-rationale.md` documents the absorption

### 8.3 — `audit_e2e` flake diagnosis (#482)

`docs/audit-e2e-flake-diagnose-2026-08-16.md` documents the
three hypotheses for the
`audit_e2e_deep_run_has_exact_external_coverage` flake:

1. Race condition in `tokio::process::Command::spawn` of the
   proxy vs the upstream response (5 s window in
   `wait_for_proxy_port`).
2. `stderr_drain` buffer truncation that drops the last
   `event:"response"` line before `external_audit.jsonl.gz` is
   flushed.
3. CRC32 of the gzip stream under `flate2` with parallel
   writer.

The decision is to formalise the test as opt-in permanent:
keep `#[ignore]`, document that the test runs only in
`make gauntlet` (not in `make test-ci`), and add no CI step
that auto-promotes it to active.
